# My Java Development Showcase

Welcome to my Java repository! This repository serves as a central hub for my personal Java projects, self-study assignments, and experimentations as I build my skills as a software developer. 

The projects here showcase my progress in learning object-oriented programming (OOP), software design patterns, database integration, and user interface development.

---

## 🎯 What I'm Practicing & Learning

Across these projects, I am exploring several core areas of software engineering:

*   **Database Integration & DAOs:** Connecting Java applications to databases (such as MongoDB and SQL), managing connections, and utilizing the Data Access Object (DAO) pattern to cleanly separate database operations from business logic.
*   **Command Line Interfaces (CLI):** Creating interactive, user-friendly console applications with menu systems, input validation, and clean text formatting.
*   **Graphical User Interfaces (GUIs):** Designing desktop applications using modern frameworks like JavaFX and FXML to build responsive and interactive layouts.
*   **Software Architecture:** Structuring applications using clean code principles, separating files into logical packages (`models`, `dao`, `service`, `ui`, `config`), and managing dependencies.
*   **Business Logic & Simulations:** Modeling real-world systems like financial tracking, payment workflows, and management systems to solve logic-heavy problems.

---

## 🛠️ General Tech Stack & Tools

*   **Language:** Java (JDK 17+)
*   **Frameworks:** JavaFX, FXML (for GUI projects)
*   **Database:** MongoDB Atlas, MongoDB Java Driver
*   **Development Environment:** VS Code / IntelliJ IDEA / Git

---

## 🚀 How to Run the Projects

Since this is a collection of individual projects, each project has its own entry point (a `main` method). To run any of them:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/jmarkTheDeveloper/Java.git
    ```
2.  **Open the repository** in your favorite IDE (VS Code or IntelliJ).
3.  **Navigate into the specific project folder** you want to explore.
4.  Locate the main class (usually containing `public static void main(String[] args)`) and run it.
